└─ .v277-profile-body           固定 height:486px + margin-top:-1px + 圆角 29px
    ├─ .v277-profile-tabs       3 等分页签：Agent 动态 / 能力 / 勋章
    └─ 页签内容

### 2.2 为什么"东西不缺但不好看"——四条硬原因

1. **高度写死**：hero 388 + body 486 = 874px，正好卡进 430×932 的视口。内容多一少一都不自适应 ——
   名字那行下面永远一大块空，页签里只有一条空态卡时下面又是一片白。
2. **hero 是照贴图复刻的**：`background-size:402px 867px`、按钮 `opacity:0` 的绝对坐标
   （`.share-hit{top:49px;right:66px}`）。那儿的留白不是设计留白，是**贴图上留白的位置**。
3. **信息层级平**：名字 20px、@handle 15px、简介 15px、标签 12px 全挤在一条中轴线上，
   没有主-次-辅的落差（NN/g 视觉层级：层级靠字号/字重/颜色的**对比**建，靠间距分块）。
4. **同一件事说两遍**：昵称 = @handle = 手机号；「设置背景」和「编辑资料 → 更换封面」重复（你自己也点出来了）。

## 3. 竞品是怎么摆的（已知形态 + 规范依据）

### 3.1 个人主页的骨架：几乎所有人共用的五段

| 段 | 放什么 | 谁这么做 |
|---|---|---|
| ① 身份区 | 封面（可选）+ 头像压在封面下沿 + 名字 + 次级标识（@handle / 等级 / 徽章） | 小红书、抖音、Instagram、X、LinkedIn、B 站；微信只有头像+名字+微信号 |
| ② 一句话简介 | 一行，超长截断 | 小红书 / 抖音 / Instagram / LinkedIn 都有 |
| ③ **数字条** | 社区产品放关注/粉丝/获赞；**我们放**：成果 / 能力卡 / 勋章 / 理解度 | 抖音（作品/喜欢/收藏）、小红书（关注/粉丝/获赞）、Instagram（posts/followers/following）、B 站（投稿/粉丝） |
| ④ 动作按钮 | 一个主按钮（编辑资料）+ 次按钮（分享、设置图标） | 所有人；Instagram「Edit profile」、小红书「编辑资料」都在同一行 |
| ⑤ 内容区 | 页签（作品/收藏/…）或流水 | 抖音/小红书/B 站用页签；Instagram 用图标页签 |

规范侧：NN/g《Visual Hierarchy》——主次要清，用户 50ms 内形成整体印象；
《Aesthetic and Minimalist Design》——每个多余元素都在抢注意力；Apple HIG——账号/身份信息要少而准。

### 3.2 我们和竞品的关键差异（决定了不能照抄）

| 差异 | 竞品 | 我们 | 后果 |
|---|---|---|---|
| 这是谁的页 | 给别人看的**主页**（粉丝/获赞） | 给我自己 + PA 看的**档案**（理解度/能力/勋章） | 数字条要有，但不是社交数字；要显"我长出了什么"，不是"我多受欢迎" |
| 内容是什么 | 笔记/视频是主角 | 产物才是主角（成果、能力卡、动态） | 页签要"一眼看清全部资产"，不做瀑布流 |
| 空态频率 | 新号也有内容 | 新用户**一片空**（我们就是不种样板数据） | 空态是一等公民（NN/g 三准则：说清状态、教怎么开始、给**直接入口**——我们三条都做到了，但视觉上没区分度） |
| 隐私 | 主页默认公开 | **默认只自己可见**（`profile.publish` 默认关） | "公开主页"要放在设置里，且必须有明确的确认动作 |

**这两张图对我们最直接的三条启发**：

1. **数字条是标配**：都是"数字大、标签小、三格等分"。我们要摆四个数（成果/能力卡/勋章/理解度）也照这个排。
2. **简介空态是可点的占位句**（小红书直接写"点击这里，填写简介"）——比我原来提的灰字占位更进一步，点一下就进编辑。
3. **设置的位置**：小红书是**「编辑资料」右边一个齿轮**（同时左上 ☰ 里还有更多），抖音是**右上角「…」**；
   小红书**也把「设置背景」放在封面右上角**——也就是说我们现在的"设置背景"是**学小红的**。
   所以你有两个选择（§7 里有对比）：
   **A（你的方案）**：封面右上角换成「设置」；
   **B（更像小红书）**：封面右上角保留「设置背景」，把**齿轮设置**放到「编辑资料」右边——反正编辑资料里也能换封面，
   但用户一眼能看懂"这儿能改背景"，不会以为封面色块是坏了的。

### 3.4 规范怎么说"设置"

- **Apple HIG · Settings**：系统设置管系统级的东西（网络/账号/隐私授权/语言）；
  应用只放**影响整个应用体验**的设置（界面风格、保存行为）；**只影响某个任务的选项就放在那个任务里**。
  → 对我们的含义：「用它做一件事」里的参数不要搬进设置页；设置页只放"全局的、跟我这个人有关的"。
- **Apple HIG**：别重复系统已有设置；默认值要服务大多数人（少让用户配）。
- **NN/g · Progressive Disclosure**：主屏只给常用项，高级/少用项藏二级屏，不要一次糊在脸上。
- **NN/g · Flat vs Deep**：太浅→选择过载；太深→找不到。**两三层、每组 3–6 项**是舒服区。
- **NN/g · "View All"**：列表只放前几条 + "查看全部"是标准做法，但别让它成为唯一入口（我们 Agent 动态那栏正好符合）。

## 6. 设置：入口 + 信息架构

### 6.1 入口（同意你的方案，再补两条理由）

- 第四页右上角那颗胶囊 = **「设置」**，点开现在的设置页；
- **「设置背景」这个胶囊删掉**（它和「编辑资料 → 主页形象 → 更换封面」是同一件事，而且今天点了没用）。

为什么右上角对：竞品里"设置"的标准位就是**右上角图标**（抖音三条杠、X / LinkedIn 的更多）或**列表最底**（微信）；

### 11.6 编辑资料页这一屏（第二轮补的）

**调研依据**（这一轮补的实证）：

| 证据 | 说明 |
|---|---|

所以这一屏改成：

1. **形象区**：封面（空态=虚线框＋居中「建议 16:9」；右上角「上传封面」/「更换封面」，点整块都能换）

2. **字段行**：昵称 / 用户名（灰显「登录账号，不可修改」）/ 个人简介 / 领域标签。

   - 昵称就是登录账号时，页面给一句提示（"换个别人看得懂的称呼，主页上就不会出现手机号了"），**不偷偷改用户的数据**。
3. **主页展示**：开关改成真的（见上表）。
4. 底部一句说明 + 「去看它记住了什么」（进记忆库）。

**新增探针** `page4-profile-edit-check.mjs`（19/19）—— 它验的就是**闭环**：
改名/改简介/加标签 → 保存 → **回到主页看是不是真的变了**；开关关掉 → 主页的 Lv 胶囊和理解度那格**真的消失**，
再打开恢复；用户名那行是只读的。

两者的共同点就是**给选项让人挑，不给空白输入框** —— 和用户说的完全一致。
