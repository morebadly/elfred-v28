## 新服务运行方式

使用 Node ≥22.13（原生 SQLite），Linux 上安装依赖和构建：

```sh
npm ci
npm run build:local
ELFRED_PORT=3001 ELFRED_PUBLIC_ORIGIN=https://your-domain.example \
  ELFRED_DATA_DIR=/absolute/private/v28-data npm run start:local
```

模型配置放在服务器私有 `.env.local`，不得放进 Git 或公开压缩包。`ELFRED_PUBLIC_ORIGIN` 必须是实际访问源（协议、域名、可选端口），不能包含路径；HTTPS 登录会话使用 Secure Cookie。

Nginx 代理到 `127.0.0.1:3001`，转发 `Host $http_host`，关闭 SSE 缓冲，读超时至少 60 秒。不能沿用把 Host 强制改成回环地址的旧配置，否则登录和保存会被拒绝。站点 `/` 在生产模式重定向到 `/v28`。

使用现有 PM2 或 systemd 托管 `scripts/start-local.mjs --production`，明确指定满足版本要求的 Node。必须启动这项统一服务；普通 Next 或旧 Vinext 启动方式没有当前业务 API。
