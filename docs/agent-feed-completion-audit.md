仍需外部条件：RSS 必须由用户提供并授权具体来源，应用不会自行猜测或订阅私人信息源。网页检索、图片生成、向量语义检索和 Jev 各自需要对应服务配置；文本模型 Key 不能等同这些服务已接通。RSS 本身不需要模型 Key，但只提供基于标题或摘要命中关注词的待核对线索，不能替代模型对全文事实的核验。
