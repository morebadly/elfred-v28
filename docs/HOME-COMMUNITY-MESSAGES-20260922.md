# 首页（含社区）与信息页：本轮实现记录

范围依据：用户明确只重点负责首页与信息/消息页，首页顶部社区也属于本人负责范围；特别要求注意首页五个 Agent 的等级。沿用现有手机框架、卡组、五列 Agent、社区和消息列表样式。

## 五个 Agent 等级

- 根据正式方案 D09 和《五个子 Agent 定义与调度方案》5.2/5.3，显示“明确信息、理解待验证、场景已验证、跨时间稳定”，替换真实页面中统一的“本人”。没有领域理解记录时显示“尚无足够理解”。
- 按探索/参谋/创作/连接/执行分别读取所属领域记录。全局记录不会自动给五个系统升级；不同阶段混合时显示“理解不一致”并列明各条依据，不平均成分数。
- 首页点击等级文字，或进入 Agent 后点击顶部名称，可查看专属等级详情、阶段说明、适用用途、确认与修正入口、情境证据，以及新增领域理解的入口。
- 撤销、删除、被替代、过期和搁置的条目不继续计入。调用次数、收藏数量和任务数量不计算等级，也不扩大权限。
- 数字经验值、游戏化奖章与全局成长面板不在本轮冒充完成；本轮是首页五系统的证据阶段展示及操作承接。

## 首页简报

- 从服务端保存的偏好读取作息与样式，按用户时区选取时段，支持跨午夜作息；当天摘要过滤未来计划和历史已完成任务。
- 早间勾选任务并确认后，持久保存今日重点；午间填写下一步调整并确认后，同步写回同一任务，详情与列表可读取。
- 简报使用事实快照和任务版本，旧版本被拒绝；整批调整原子提交，幂等重试不重复写入。更新简报或来源失效后，不再提交旧选择。
- 安排确认不会自动启动任务或把草稿变成已完成。任务状态徽标与下一步说明分开显示。

## 社区与信息页

- 首页社区增加普通文字动态发布、作者编辑、撤下、评论、点赞、收藏和隐藏；普通动态与共创项目在发布入口中分开选择。撤下后原帖与评论不能继续读取或检索。
- 共创项目增加停止/重新开放招募；停止期间不能加入或批准申请，已有成员和成果保留。
- 真人私聊名称显示对方；列表按最近更新排序；搜索覆盖历史消息正文，并跳到对应会话高亮原消息。取最新 50 条匹配，未伪称无限消息历史索引。
- 提及通知和收件箱按目标类型正确跳转；辅助面板投影真实任务状态；群主可改群名、邀请已建立关系的好友，其他成员无管理权限。
