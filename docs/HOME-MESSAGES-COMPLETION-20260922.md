# 首页、真人社区与信息页：本次补全记录

## 页面与业务

- 社区中部改为一个发布入口与可展开的“我的共创”。修复项目卡误用 50px 缩略图列造成的文字挤压、溢出；保留原首页五 Agent、社区信息流、任务播放器和底部导航。
- 真人社区：账号本人发帖、编辑、撤下、评论；图片和文件附件由发布操作明确公开。Agent Runtime 没有发帖、评论或发送消息的工具。Agent 朋友圈仍为本人私有的验收进展。
- 共创：私有项目草稿→本人发布招募→多个任务位（人数、截止日期、前置依赖）→认领/申请/批准/撤回→独立副本→本人核对提交→发起人采纳/退回/拒绝→发布/回滚/署名再创作。并发贡献保留版本冲突，不覆盖现有正式成果。
- 作品：文本与单文件 HTML/CSS/JavaScript。保存检查脚本语法；预览在无同源权限、无外部连接的 iframe 中运行；Mini App 与社区成果共用受权限保护的预览接口。服务端不执行用户代码。
- 我的工具：Skill / Mini App / Agent 分类、版本、测试、启用/归档、固定、最近/常用、使用记录。任务引用确定的工具版本，新版本不改变已创建任务。Mini App 已在浏览器点击计数器验证真实执行。
- 首页：五 Agent 的理解依据各自独立；动态可拖入或点选存入收件箱，再整理为需本人确认的任务；晚间反思可保存明确的后续待办或待确认理解。
- 检索：本地关键词、来源定位、消息定位；另可明确选择至多 20 份资料创建语义核对任务，逐条件给出依据和未知项。语义核对使用模型，不会默认把整个知识库或聊天记录发送出去。
- 消息：真人消息与 @、草稿、图片/文件/音频附件、录音、语音转写回填；历史消息分段显示，另有服务端游标接口；EventSource 事件更新并保留断线轮询。发送期间冻结草稿编辑入口。
- 群协作：共享目标/结论/分歧/简报/日程候选；事项由负责人接受，修改后重新确认，可撤回；截止时间可导出 `.ics`。修改群事项不会暗中取消旧的个人任务。
- 私密辅助：消息选择、用途快捷项、明确模型授权、结果笔记、追加/替换/恢复草稿；最后仍由本人发送。
- 文件：每个附件最大 8 MB。文本/PDF/Word/PowerPoint/Excel 提取到资料；本机已具备 Python、pdftotext。解析最多保留 500000 字，模型上下文逐份最多读取 12000 字并标记截断。图片识别和语音转写走服务端模型接口。
- Agent：按五系统和专业角色选择职责，按授权资料读取→生成→独立模型审查→需要时一次修正；最终验收由本人决定。默认累计上限 8 次工具调用、180 秒、16384 tokens、6000 本地额度，至多 1 次本人反馈修订。恢复检查点不会重复已完成步骤，长运行续租。

## API Key 配置

在项目目录运行：

```powershell
powershell -NoProfile -File scripts/configure-model.ps1
```

输入只保存在本机、已被 Git 忽略的 `.env.local`，不会回显到终端。然后重启 `npm run start:local`。

默认是 OpenAI 的 `gpt-4.1-mini`（文本/图片）与 `gpt-4o-mini-transcribe`（语音）。使用 OpenAI Key 时无需填写其他模型字段。已有兼容服务可以在环境文件中设置 `ELFRED_MODEL_BASE_URL`、`ELFRED_MODEL_NAME`、`ELFRED_AUDIO_MODEL`，该服务须实际支持相应接口。模板见 `config/model.env.example`。

接口依据：[模型说明](https://developers.openai.com/api/docs/models/gpt-4.1-mini)、[语音转文字](https://developers.openai.com/api/docs/guides/speech-to-text)、[视觉输入](https://developers.openai.com/api/docs/guides/images-vision)。

模型额度是应用内调用单位，不代表货币费用。请求前预留文字及图片输入预算；失败未知用量保留费用与 token 预算，先对账，不能当作零成本继续重试。已知超限用量计入累计值。未知 token 用量保守占满原任务剩余 token 预算，需另建明确的新任务。
