# 五系统专业能力轻量化 · 2026-09-22

## 已实现

保留探索、参谋、创作、连接、执行五个顶层 Agent 及原首页排版和等级证据规则。17 项默认职责改为版本化、按任务加载的配置，共用现有运行器；不会注册 17 个常驻模型实例，也不会复制用户记忆。

| 系统 | 按需能力 |
| --- | --- |
| 探索 | 调研 Skill、观察流程、核验流程 |
| 参谋 | 分析 Skill、决策 Skill、风险检查 |
| 创作 | 文稿创作 Skill、视觉媒体制作方案 Skill、软件原型 Skill、编辑审校流程 |
| 连接 | 匹配 Skill、关系 Skill、协作 Skill |
| 执行 | 执行规划 Skill、操作准备流程、运行监督分析流程、结果验收流程 |

每项配置含工作步骤、输出结构、检查项、工具白名单、上下文范围、版本与实际限制。只给本次所选能力加载专业指令。普通生成任务默认一轮模型调用；提供资料、指定独立复核，或核验/风险等任务，在预算允许时增加独立审查，且只在审查要求修改时修订一次。预算不足不会伪造已审查，结果仍待本人核对。模型通过不等于自动验收。格式检查仅提示缺失章节，不判定事实正确。

移除生成前重复的 context.read 步骤，资料直接进入同一次生成上下文。暂停恢复沿用已冻结的能力、复核者、计划和方法，不重做成功步骤。审批、资料权限、累计额度、人类验收、社区真人发送边界保持有效。人工验收保留原复核记录。

## 使用入口

- 各 Agent 详情：展开“内置专业能力”，查看该系统能力。
- 我的工具 → Skill：展开全部 17 项内置能力。现有用户工具、Mini App、自定义 Agent 保留。
- 选择能力 → 填目标 → 勾选最多 20 份可读文档/知识/资源 → 选择复核方式 → 创建草稿。
- 任务详情查看能力、资料版本和检查项，确认后启动。

## Jev 与外部能力边界

capability-selector.mjs 提供 Choice 问题生成及可信服务端候选结果校验。默认本地规则选择；跨系统、低置信、none 或非法建议回退。客户端不能通过任务参数伪造裁判建议、增加工具或扩大权限。

**未接入真实 Jev 网络调用，不能仅填 Jev Key 就宣称已启用。** 当前为后续服务端适配器预留契约；Jev 只适合辅助选择和判断，实际文字/代码仍由生成模型完成。

外部联网检索、持续外部监控、人才数据库、图片/视频/音频生成，以及邮件/浏览器操作/支付/部署工具均尚未接通。对应能力现在交付资料分析或制作/操作方案。Mini App 沿用单文件网页沙箱预览，不等于任意后端构建部署。不得把规划文字当作执行回执。
