## 已执行的验证

- `npm test`：24/24 通过，涵盖原版布局、导航、初始化、任务状态和反思边界。
- `npm run test:runtime`：33/33 通过，覆盖 HTTP/CSRF、双用户隔离、幂等/CAS、预算/调度/检查点、撤权、消息草稿、共创、记忆、方法评估、备份恢复及真实前端模块的请求竞态。
- `npx tsc --noEmit`、`npm run build:local`：通过。构建包含 `/`、`/v28`、`/prototype`、`/u/[handle]`。
- Lint 错误已修复；仍有 Hook 依赖、未使用变量警告，不能宣称零警告。
- 浏览器：原界面创建检索任务 → 确认 → 命中已有文档 → 本人验收 → 知识库保存 → 刷新保留。
- 浏览器 + Bob 的 HTTP 会话：Alice 申请好友 → Bob 接受并发送 → Alice 看到姓名/未读/正文 → 草稿刷新重入保留 → 发送 → Bob 读取同一消息（序号 2）。
- 浏览器 + Bob 的 HTTP 会话：Alice 加入共创 → 创建/保存副本 → 本人核对并提交 → Bob 采纳/发布 → Alice 看到正式修订 1、审核反馈和当前发布版本。
- 备份恢复在隔离临时数据库执行，未覆盖当前开发数据，恢复前副本保留。
- 独立复审修复：退出后旧请求恢复账号、草稿新版本配旧正文、跨页面副本覆盖、留出评估丢失项目权限；均补回归。

模型测试使用明确标记的测试 Provider，只验证调用、权限、预算、回执和人工门控，不代表外部真实模型调用通过。浏览器只使用本地 `qa_alice` / `qa_bob` 测试账号。
