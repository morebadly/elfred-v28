## 已实现

- 真人聊天由用户在输入栏键入 @ 打开本人 Elfred（按用户补充要求取消常驻 @ 按钮），保留人类草稿；去除真人成员 @ 菜单。服务器历史 mention 数据兼容接口保留。
- 在同一个输入栏直接输入“搜索 / 检索 / 查找 + 关键词”，查询当前账号可读资料，结果可返回原来源。此检索为现有本地关键词检索，不假称联网或向量搜索。
- 私密请求选择参考消息、本人资料或参与者公开近况；明确模型同意后运行。对方不接收辅助内容、通知或未读变化。无 Key 请求保存为 blocked。
- 结果追加/替换前预览；预览固定草稿版本，过期后须重做；回填本身不发送。保留恢复上一次草稿入口。
- 久未聊天的私聊单独显示可关闭的“准备开场”入口。当前本地判断参数为无消息或最后一条消息距今至少 7 天，是实现参数，尚未经过产品实验定型。AI 使用用户选中的历史聊天和公开近况，不读取对方私库。未授权时不预先调用模型。
- 新账号直接进入初始化对话；旧账号从“我的 → 继续与 Elfred 的初始化对话”进入。文本草稿和对话记录持久保存，离开页面先保存；跨页面版本冲突不会覆盖未见过的输入。
- 未使用模型时显示明确标记的引导问题；授权后经真实任务运行模型生成自然追问，单轮一次调用。未配置 Key 不显示伪造回复。
- 初始化支持图片；文字/PDF/Office 自动提取正文后才引用；音频通过语音输入转写并由本人回填。解析失败保留输入供修改。
- 核对可编辑目标、选择主责 Agent 与最多 20 份资料，确认后幂等建立一个首任务草稿。可选保存“待确认理解”，不会直接提升五个 Agent 的理解等级。
